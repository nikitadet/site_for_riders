# site_for_riders
сайт для райдеров, чтобы они могли понять какой грунт они ожидают на той или иной территории


что использовал:
-ГОСТ 25100-2020 «Грунты. Классификация». Классификации грунтов — это система, которая помогает инженерам и геологам понять свойства грунта, чтобы правильно проектировать фундаменты, дороги или другие сооружения.
- данные о преобладании грунта на споте в филёвском парке
