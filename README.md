# site_for_riders
сайт для райдеров, чтобы они могли понять какой грунт они ожидают на той или иной территории
сам сайт: https://nikitadet.github.io/site_for_riders/


что использовал:
- ГОСТ 25100-2020 «Грунты. Классификация». Классификации грунтов — это система, которая помогает инженерам и геологам понять свойства грунта, чтобы правильно проектировать фундаменты, дороги или другие сооружения. https://files.stroyinf.ru/Data/738/73839.pdf?ysclid=mwji07jkbg499033101
- данные о преобладании грунта на споте в филёвском парке
